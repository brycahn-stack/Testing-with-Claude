# Build and Setup

Part of [[Voice Journal]]. How to go from repo → running app.

## Requirements

- **Xcode 16+ / Xcode 26** (iOS 17 / watchOS 10 deployment targets)
- **XcodeGen 2.38+** (`brew install xcodegen`) — generates the `.xcodeproj` from
  `project.yml` so the repo stays free of the merge-prone `.pbxproj`
- **GitHub CLI** (`gh`) for cloning the private repo

## First-time setup

```bash
# Authenticate once (private repo; HTTPS password auth is disabled by GitHub)
brew install gh
gh auth login          # GitHub.com → HTTPS → Yes → Login with a web browser

# Clone, switch to the feature branch, generate, open
cd ~/Documents
gh repo clone brycahn-stack/Testing-with-Claude
cd Testing-with-Claude
git checkout claude/watchos-voice-journal-60enrm
cd VoiceJournal
xcodegen generate
open VoiceJournal.xcodeproj
```

> The app code lives on branch `claude/watchos-voice-journal-60enrm`. `main` is
> still just the README.

## In Xcode

1. **Signing:** on the `VoiceJournal` and `VoiceJournalWatch` targets →
   *Signing & Capabilities* → set your Team. (Or set `DEVELOPMENT_TEAM` in
   `project.yml` and re-run `xcodegen generate`.)
2. **First build:** pick an **iPhone simulator**, scheme **VoiceJournal**, ⌘B.
   No signing needed for a simulator build — it just checks the code compiles.
3. **Tests:** ⌘U runs the categorizer + router unit tests (no devices needed).
4. **Full experience:** run on a **real paired iPhone + Apple Watch** — mic
   capture and watch→phone transfer don't work in the simulator.

## Regenerating

Any time `project.yml` changes (new files, settings, targets), re-run
`xcodegen generate`. The Info.plists are generated by XcodeGen (from the `info:`
blocks in `project.yml`) and are gitignored.

## Gotchas

- **Xcode 26 defaults toward Swift 6** strict concurrency; the project pins
  **Swift 5.9 language mode** on purpose so `@MainActor` constructions stay
  warnings, not errors.
- **Older XcodeGen** (< 2.38) can't do the multiplatform `VoiceJournalCore`
  framework — `brew upgrade xcodegen`.
